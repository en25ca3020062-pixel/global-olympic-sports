🏅 Olympic Performance Analysis

📌 About the Project

Olympic Performance Analysis is a data analytics project built using Tableau. It explores Olympic medal performance, sports investment, and athlete development through data visualisations.

🛠️ Tools Used

- Tableau Public
- CSV Datasets
- Data Analytics

📊 Project Scenarios

1. NOC Performance Analysis

- Country-wise medal comparison
- Gold, Silver, and Bronze distribution
- Athlete participation vs medal outcomes

2. Financial & Strategic Planning

- Sports investment and medal efficiency
- Regional performance comparison
- Host nation advantage

3. Talent Analytics

- Athlete peak performance age
- Physical characteristics by sport
- Training hours and medal performance
- World record analysis
